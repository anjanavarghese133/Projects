# Projects
My QA testing repository, with manual and automated test cases, bug reports, and findings organized by application. It records how I plan, execute, and report testing, and serves as a basis for tracking my skills and performance over time.

Projects is a structured repository documenting my hands-on work as a Software Tester. It is not simply a collection of scripts or applications. It is a record of my findings, methodologies, and professional growth across both manual and automated testing.

The repository is organized to reflect real-world QA workflows. Work is separated into two primary directories, Automation and Manual, and each is further grouped by the application or website under test. For example, the Automation folder contains a dedicated section for palakkad.lulumall.in. Every project folder includes three core components: test files and scripts, detailed test cases that define objectives, preconditions, steps, and expected results, and bug reports that record defects with reproduction steps, severity, priority, and supporting evidence.

This consistent structure allows the same application to be examined through both automated and manual approaches, making it possible to compare coverage, efficiency, and defect detection across methods.

Beyond storing artifacts, the repository is designed to be analyzed. Its test cases, defect records, and execution outcomes provide a transparent basis for evaluating testing skills, tracking performance over time, identifying recurring defect patterns, and measuring coverage across projects. Each entry serves as evidence of analytical thinking, attention to detail, and the ability to communicate issues clearly to development and product teams.

The repository is intended for hiring managers, fellow QA professionals, and development teams who want to see how testing is planned, executed, and reported in practice. It reflects a commitment to quality that goes beyond finding bugs: documenting them thoroughly, reproducing them reliably, and helping teams deliver better software.
